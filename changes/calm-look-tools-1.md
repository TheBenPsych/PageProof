title: The calm look, step 17: All tools and Verify a pack
news: Tools › All tools now shows only the six real tools (Inspect a photo, Compare two photos, Mark up a copy, Convert files, Open odd files, Verify a pack), each saying what it takes. The ten cards that only jumped to other tabs are gone, they are in their own menus. On top is one box: drop any file there (or press Choose a file) and PageProof opens the right tool, a photo opens Inspect, two photos open Compare, an evidence pack (.zip) opens Verify, a capture PDF opens Mark up, and anything else opens Convert. Opened lately lists the files you opened in a tool, with the tool and the time, and Open again. That list is kept only on this computer and is not part of the backup. Verify a pack moved into the Tools menu and has the new look: one big answer (green Nothing has changed since it was made, yellow when there are no timestamps, red when something was changed), four tiles (files that match, timestamps signed, when it was captured, same zip as in your capture log), the capture details as rows, the trusted timestamps as rows, and the file names in a fold that opens by itself when a file does not match. The checking itself has not changed, and the checker placed inside every evidence pack keeps its plain look.
