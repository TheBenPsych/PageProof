title: Searches run in their own minimized window
news: Every search tab (Keep searching, Google Lens, Yandex, Bing and owner checks) now opens in one separate "PageProof searching" window that stays minimized, so your own window has no pinned search tabs. If a site asks "are you a robot?", clicking the notice opens that window on the right tab. Closed by mistake? A new one opens the next time PageProof searches. It closes by itself with your last browser window. To go back to pinned tabs: Keep searching › How it searches › Where searches run › Pinned tabs.
